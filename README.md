# 주소록 (Android Web / PWA)

`AddressBook_v5_11.py` (Tkinter 데스크톱 앱)을 안드로이드 브라우저에서 쓸 수 있는
설치형 웹앱(PWA)으로 이식한 버전입니다.

## 파일 구성
- `index.html` — 화면 구조
- `app.js` — 검색/정렬/즐겨찾기/가져오기·내보내기 등 전체 로직
- `manifest.json` — 홈 화면에 앱처럼 설치하기 위한 PWA 설정
- `sw.js` — 오프라인에서도 열리도록 하는 서비스 워커
- `icon-192.png`, `icon-512.png` — 앱 아이콘

## 데이터 저장 방식
- 서버가 없는 **정적 웹앱**입니다. 모든 연락처·즐겨찾기·최근기록·설정은
  해당 브라우저의 `localStorage`에만 저장되며 외부로 전송되지 않습니다.
- 기존 `visit-log` 프로젝트처럼 GitHub Pages에 올리면 그대로 동작합니다.
- 브라우저 데이터(사이트 데이터)를 지우면 저장된 연락처도 함께 삭제되므로,
  주기적으로 설정 → 내보내기(JSON)로 백업하는 것을 권장합니다.

## 배포 방법 (GitHub Pages 예시)
1. 이 폴더 전체를 새 저장소(예: `address-book-web`)에 올립니다.
2. 저장소 Settings → Pages → Branch를 `main` / `root`로 설정합니다.
3. `https://artofstock.github.io/addressweb/` 로 접속되면 완료입니다.
4. 안드로이드 크롬에서 접속 후 우측 상단 메뉴 → **"홈 화면에 추가"**를 선택하면
   일반 앱처럼 아이콘이 생기고 전체화면으로 실행됩니다.

로컬에서 미리 확인하려면 이 폴더에서 아래처럼 간단한 서버를 띄우면 됩니다
(서비스워커·매니페스트는 `file://`로 열면 정상 동작하지 않습니다):
```
python3 -m http.server 8000
```
그 후 같은 와이파이의 안드로이드 폰에서 `http://<PC의 IP>:8000` 으로 접속해 테스트할 수 있습니다.

## 데스크톱 버전 대비 이식/변경된 기능
| 데스크톱(Tkinter) | 웹(안드로이드) |
|---|---|
| SQLite DB (`address.db`) | 브라우저 `localStorage` |
| 엑셀/CSV 가져오기 | 동일 (CSV/XLSX/JSON, 브라우저에서 직접 파싱) |
| CSV/JSON/XLSX 내보내기 | 동일 |
| 검색(AND/제외/정확일치/OR/초성) | 동일한 문법 그대로 지원 |
| 정렬 (컬럼 클릭) | 상단 칩(이름순/팀명순/직책순) |
| 즐겨찾기 / 최근 열람 | 동일 |
| 팀별·직급별 통계 | 동일 (막대그래프) |
| 우클릭 컨텍스트 메뉴 | 길게 눌러 다중 선택 → 하단 작업 시트 |
| mailto 메일 발송 | 동일 (mailto:) |
| — | **추가:** 연락처 탭 한 번으로 전화 걸기(`tel:`), 문자 보내기(`sms:`) — 모바일 전용 기능 |
| — | **추가:** 오프라인 사용 가능(서비스 워커), 홈 화면 설치(PWA) |

## 검색 문법 (기존과 동일)
```
홍길동          → 여러 단어 AND
"홍길동"        → 정확 일치
팀장 -홍        → "팀장" 포함, "홍" 제외
홍|김           → "홍" 또는 "김"
ㅎㄱㄷ           → 초성 검색
```

## 커스터마이징 포인트
- 기본 메일 도메인은 앱 내 **설정 → 메일 도메인**에서 변경합니다
  (Python 버전의 `DEFAULT_MAIL_DOMAIN` 상수에 대응).
- 직책별 배지 색상은 `index.html`의 `--job-1` ~ `--job-14` CSS 변수와
  `app.js`의 `JOB_COLOR_ORDER` 배열 순서를 맞추면 됩니다.
